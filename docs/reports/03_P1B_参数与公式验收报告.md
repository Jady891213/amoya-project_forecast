# P1B 参数与公式验收报告

更新时间：2026-07-28
状态：已通过

## 一、验收结论

P1B 已在 P1A 的固定月金额、逐月填写和计算批次基础上完成参数与公式闭环：

```text
项目参数
  + 收入、成本、收款、付款行项目
  + 参数或上游行引用公式
  → 分月编译
  → 行项目级结果
  → 指标事实
  → 计算表格与项目报表
```

财务用户可以在同一项目工作区维护固定或逐月参数，通过“单价 × 数量”“收入 × 比例”等公式生成预测结果。公式计算不调用 AI，也不执行 JavaScript、SQL 或自定义脚本。

## 二、Schema v5 迁移结果

Schema v5 新增：

- `cfg_parameter`：项目参数、稳定编码、类型、单位、固定值和排序。
- `cfg_parameter_value`：逐月参数值。

Schema v5 调整：

- `cfg_forecast_line.forecast_method` 增加 `formula`。
- `cfg_forecast_line.formula_expression_text` 保存稳定编码表达式。
- `sys_calculation_run.config_snapshot_json` 保存不可变计算配置快照。

自动化验证结果：

- 空库可以完整迁移到 v5。
- v1 至 v4 数据库启动或导入后可以幂等升级。
- 迁移不修改既有项目、维度、事实和成功计算结果。
- 数据库备份恢复后，参数、公式、批次快照和结果保持一致。

## 三、公式计算用例

| 用例 | 表达式示例 | 结果 |
|---|---|---|
| 固定参数相乘 | `PARAM("PAR-001") * PARAM("PAR-002")` | 通过 |
| 逐月参数 | 注册用户 × 月单价 | 各期间读取对应参数值 |
| 行项目引用 | `LINE("LINE-001") * PARAM("PAR-003")` | 通过 |
| 运算优先级 | 加减、乘除和括号混合 | 通过 |
| 负数与百分数 | `-100 + LINE("LINE-001") * 20%` | 通过 |
| 多级依赖 | 参数 → 收入行 → 分成成本行 | 按拓扑顺序计算 |
| 上游行超出生效期 | 引用不在生效期的行 | 当前期间按 0 |
| 逐月参数缺值 | 公式需要但未填写 | 阻止计算并定位期间 |
| 缺失引用 | 参数或行编码不存在 | 阻止计算并定位行项目 |
| 除零 | 分母为 0 | 阻止计算 |
| 循环引用 | 两个或多个行相互引用 | 阻止计算并说明依赖环 |

所有金额和比例运算使用 Decimal.js；没有使用 JavaScript 浮点数直接汇总。

## 七、已知限制

P1B 不包含：

- 税率和含税/不含税转换。
- 收付款账期和从损益自动生成现金流。
- 多场景参数覆盖。
- 只读版本快照和场景比较。
- Excel、CSV和图表报告导出。
- 跨项目分析、审批、多用户协作和工具内置 AI。
