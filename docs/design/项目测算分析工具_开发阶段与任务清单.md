# 项目测算分析工具：开发阶段与任务清单

更新时间：2026-07-28  
状态：持续维护

> 本文件是阶段范围和完成状态的唯一执行基线。原型只用于理解布局，不代表功能已经进入开发范围。

## 一、当前架构结论

同一套 React + TypeScript 源码生成两种产物：

- PWA 正式版：SQLite WASM + Dedicated Worker + OPFS 自动持久化。
- 单 HTML 便携版：内存 SQLite + `.sqlite3` 手动导入导出。

当前已形成的最小链路：

```text
真实项目与六类主数据（P0）
  → 收入、成本预测行配置（P1A）
  → 预测编译与计算批次
  → SQLite多维基础事实
  → 系统指标查询计算
  → 项目计算表格
  → 单项目报表
```

不建设跨项目分析。用户真实项目不会自动附加参考事实；第一次真实“保存并计算”后，当前项目工作版只使用新批次结果。

## 三、P1：预测配置闭环

### P1A 收入、成本预测配置闭环

#### Schema v3 与接口

- [x] `cfg_forecast_line` 保存行项目定义、分类、业务模块、预测方式、生效期间和说明。
- [x] `cfg_forecast_value` 保存逐月填写值。
- [x] `fact_forecast_line_value` 保存计算批次下的行项目级分月结果。
- [x] 行项目结果保存编码、名称和分类快照，配置改名或删除后仍可追溯旧批次。
- [x] `sys_calculation_run` 保存批次号、状态、配置摘要、问题和起止时间。
- [x] `fact_metric_value` 增加计算批次关联。
- [x] Schema v1、v2 可自动升级到 v3；恢复数据库后继续幂等迁移。

#### 预测配置与编译

- [x] 收入、成本行项目自动映射 `revenue`、`cost`。
- [x] 行项目稳定编码由系统生成。
- [x] 固定月金额按生效期间展开。
- [x] 逐月填写按项目期间展示，空白月按 0 计算并返回提示。
- [x] 金额允许负数并返回提醒。
- [x] 编译器为纯确定性逻辑，不调用 AI。
- [x] 保存草稿不覆盖上一批成功结果，并依据配置摘要标记结果过期。
- [x] 保存并计算创建批次、写入行项目结果、汇总基础事实，并在一个结果事务中生效。
- [x] 计算失败保留草稿和上一批成功结果，不写入半成品事实。
- [x] 新成功批次只替换当前项目“基准场景 + 工作版”的基础事实。

#### 页面闭环

- [x] 预测配置采用左侧主表、右侧无蒙层挤压表单。
- [x] 支持新增收入项、成本项、编辑、确认删除、上移和下移。
- [x] 支持保存草稿、保存并计算。
- [x] 固定月金额显示月金额、生效期间和周期合计。
- [x] 逐月填写显示已填/未填月份和合计，支持键盘连续录入。
- [x] 保存并计算成功后进入计算表格。
- [x] 计算表格显示批次号、最后计算时间、配置一致状态和返回配置入口。
- [x] 计算表格可按行项目追溯分月收入、成本组成。
- [x] 项目报表继续只读取 `fact_metric_value`。
- [x] 没有现金流事实时显示“现金流将在收付款规则阶段生成”，不展示 0 元假结果。

## 五、当前明确不做

- 跨项目报表和自由透视。
- 多人协作、权限、审核和审批。

- 任意脚本公式。
