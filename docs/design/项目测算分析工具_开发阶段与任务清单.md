# 项目测算分析工具：开发阶段与任务清单

更新时间：2026-07-28  
状态：持续维护

> 本文件是阶段范围和完成状态的唯一执行基线。原型只用于理解布局，不代表功能已经进入开发范围。

## 一、当前架构结论

同一套 React + TypeScript 源码生成两种产物：

- PWA 正式版：SQLite WASM + Dedicated Worker + OPFS 自动持久化。
- 单 HTML 便携版：内存 SQLite + `.sqlite3` 手动导入导出。

P0 最小链路：

```text
真实项目与六类主数据
  → SQLite多维基础事实
  → 系统指标即时计算
  → 项目计算表格
  → 单项目报表
```

不建设跨项目分析。用户真实项目在 P0 没有事实数据，不附加 Mock 结果。

## 三、P1：预测配置闭环（本轮未启动）

- 逐月填写。
- 固定月金额。
- 行预测配置。
- 保存并计算。
- 写入现有 `fact_metric_value`。

### P1B 参数与行项目公式

- 业务参数。
- 单价 × 数量。
- 引用参数和其他行项目。
- 四则运算、百分数、依赖排序和循环引用检查。

### P1C 税与现金流

- 税率作为一种预测方式或计算规则。
- 收付款偏移。
- 现金流基础事实生成。

### P1D 统一交付

- 图表报告。
- 统一 Excel 模板。
- 项目文件交换格式。
- 第一轮真实用户试用。

## 四、P2：多场景、版本快照与正式报告

- 基准、乐观和审慎场景。
- 参数覆盖与场景复制。
- 只读版本快照。
- 场景比较报告。
- CSV/Excel 导出。

## 五、当前明确不做

- 跨项目报表和自由透视。
- 多人协作、权限、审核和审批。
- 工具内置 AI。
- 任意脚本公式。
- 日期级资金计划。
- 客户级 Excel 模板定制。
- P0 引入 Electron、服务端或预测配置。
