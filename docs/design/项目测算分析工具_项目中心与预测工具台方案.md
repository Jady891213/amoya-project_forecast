# 项目测算分析工具：项目中心与预测工具台方案

更新时间：2026-07-27

> 功能基线说明：`docs/prototype/index.html` 已在 2026-07-27 替换为用户提供的后续优化版。它已跑通单项目的四种建模方式、含税/不含税结果、年度分布与 PDF、Excel、CSV 导出。后续服务化实现应把这些能力迁入本方案中的项目内三页链路。

## 一、最新产品结论

产品结构收敛为两级：

1. 外层是项目、平台主数据、计算指标与跨项目分析。
2. 进入具体项目后，按“预测配置—计算表格—图表报告”完成测算。

项目内部不设置独立的场景分析工作台，固定为三个页面：

- 预测配置：项目信息和分项预测方式。
- 计算表格：只读查看编译后的分月结果。
- 图表报告：查看结论、图表、方案比较并导出。

方案比较仍然保留，但作为图表报告中的一个章节，不再设置独立分析工作台。

项目生命周期保持简单，只区分“测算中”和“已归档”。版本是项目计算快照，不承担提交、审核或审批流程。

## 二、外层：项目与主数据

### 2.1 项目数据

项目中心集中展示：

- 项目名称、客户、所属部门和负责人。
- 预测周期。
- 当前版本。
- 收入、毛利等少量结果摘要。
- 最近更新时间。
- 进入项目或归档项目。

项目列表只承担项目管理和定位，不在外层展示具体预测参数、模型结构或分月明细。

### 2.2 主数据

主数据用于维护跨项目复用的标准内容：

- 项目主数据：项目保存后自动登记，只读展示项目编码、名称、客户、部门、负责人、预测周期和状态。
- 组织部门。
- 计算指标定义。
- 业务参数模板。
- 统一 Excel 输出模板。

年月、场景、版本和项目状态是系统内置维度，不需要导入或逐项维护。组织部门通过页面表格维护，第一版不提供导入导出。条线、事业部等其他组织属性没有明确跨项目分析需求前，先作为项目普通属性；出现稳定复用和跨项目汇总需求后，再升级为平台维度。

项目只能在项目中心和项目详情中创建、修改与归档，不能在主数据页面直接编辑。项目使用平台主数据，但项目自己的业务模块、假设、公式覆盖、场景值和版本快照保存在项目内部。

### 2.3 跨项目分析

跨项目分析直接读取项目计算形成的统一事实结果，按部门、项目、指标、年月、场景和版本组织视图。第一版先提供两套固定布局：

- 行为部门与项目、列为年月。
- 行为年月、列为部门与项目。

后续再扩展自由拖拽维度、钻取和保存个性化透视布局。

## 三、项目内：三个页面

### 3.1 预测配置

预测配置页面分成两部分：

1. 项目信息：客户、部门、负责人、预测开始年月、周期、默认口径和项目业务模块清单。
2. 行测算配置表：业务参数、收入、成本和现金流行项目。

项目业务模块采用“项目定义、行项目引用”的关系：项目级只定义本项目可用的模块清单，例如云游戏和超高清；每个行项目选择一个归属模块或“公共”。行项目名称、系统分类、预测方式、公式、税务口径、生效期间和账期都属于行测算配置，不属于项目基本信息。

配置表直接回显系统分类、行项目名称、归属模块、预测方式、主要公式、指标编码和完整状态。用户点击一行后，主表向左压缩并在右侧显示配置表单，不使用遮罩覆盖主表；表单负责维护行项目的预测方式、公式、税务口径、生效期间、来源和结构化映射。Excel 或 CSV 只用于导入预测参数和值，不用于创建年月、场景、版本或部门主数据。

预测配置与计算表格不是两个并行数据源，而是明确的输入输出关系：

1. 用户在预测配置页维护项目参数、行项目和公式。
2. 点击“保存并计算”，系统先保存当前工作配置，再执行模型校验和分月计算。
3. 计算成功后生成一个计算批次并自动进入计算表格。
4. 计算表格只读展示该批次结果；配置再次修改后，需要重新计算才能更新结果。

### 3.2 计算表格

计算表格是单独的只读结果页，采用“行是指标和行项目、列是年月”的财务表格形态。页面明确显示计算批次、计算时间以及结果是否与当前配置一致，并提供“返回修改配置”。用户可以切换场景、历史版本、业务模块和含税口径，并查看：

- 业务驱动参数。
- 分月收入与成本。
- 分月毛利和毛利率。
- 现金流入、流出、净现金流和累计现金流。
- 项目合计、最大垫资和现金转正月份。

计算表格不再承担预测方式配置；需要修改时返回预测配置页。

### 3.3 图表报告

图表报告读取计算表格的同一份结果，统一包含：

- 项目结论。
- 核心业务假设。
- 分月预测摘要。
- 基准、乐观和审慎方案比较。
- 现金流结果。
- 模型检查和待确认事项。

报告顶部提供场景和版本选择，并支持：

- 导出 CSV 明细。
- 按统一模板导出 Excel。

场景参数的具体编辑仍在预测配置页完成；报告只负责查看、比较、复核和导出。

## 五、页面链路

```text
项目中心
  ├─ 项目列表
  ├─ 归档项目
  ├─ 跨项目分析
  └─ 平台配置
       ├─ 主数据管理
       │    ├─ 项目主数据（保存后自动登记，只读）
       │    ├─ 组织部门
       │    └─ 年月 / 场景 / 版本 / 项目状态（内置）
       ├─ 计算指标定义
       ├─ 业务参数模板
       └─ Excel 输出模板

进入具体项目
  ├─ 预测配置
  │    ├─ 项目信息
  │    ├─ 行测算配置表
  │    └─ 右侧挤压式配置表单
  ├─ 计算表格
  │    ├─ 场景 / 版本 / 业务模块 / 口径切片
  │    ├─ 分月损益与现金流主表
  │    └─ 结果摘要
  └─ 图表报告
       ├─ 结论与假设
       ├─ 分月预测
       ├─ 方案比较
       ├─ 现金流
       └─ 检查与导出
```

## 六、持久化边界

- 部门主数据、项目、版本、行项目配置、公式、场景覆盖、计算批次、计算结果和运行记录保存在 SQLite 本地库。
- 项目首次保存后自动进入项目主数据目录，后续保存同步主要属性；主数据视图本身不创建项目副本。
- Excel 和 CSV 作为导入、交换和导出文件，不作为运行期数据库。
- 项目中心读取轻量摘要；进入项目后再加载完整预测模型。
- 项目归档不删除数据，恢复后继续生成新的工作版本。

## 七、原型基线

原型文件：

`docs/prototype/项目测算分析工具_项目中心与预测工具台原型.html`

该原型取代上一版三布局工作台，作为下一阶段讨论和开发的当前基线。

当前已实现的独立页面和交互状态：

- 项目列表：搜索、部门筛选、新建项目、进入项目。
- 归档项目：归档清单、归档原因、恢复项目。
- 跨项目分析：按部门与项目、年月查看同一事实结果，并切换两套固定行列结构。
- 主数据管理：已保存项目的只读主数据、组织部门表格维护，以及年月、场景、版本、项目状态内置维度说明。
- 计算指标定义：指标分类、编码、解释、公式、单位和聚合方式。
- 业务参数模板：模板列表、模板属性和参数明细。
- Excel 输出模板：模板列表、工作表结构、字段映射和预览。
- 预测配置：项目业务模块清单、行测算配置表、右侧挤压式配置表单和显著的“保存并计算”入口。
- 计算表格：计算批次状态、场景/版本/业务模块切片、分月损益和现金流、结果摘要。
- 图表报告：结论、假设、分月预测、方案比较、检查事项和导出入口。

这些页面使用同一个单页原型模拟路由和跨页操作；数据均为用于表达产品结构的 mock，不代表已接入 SQLite 或真实文件导入。
