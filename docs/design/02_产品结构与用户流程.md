# 产品结构与用户流程

更新时间：2026-07-28
状态：当前产品与页面结构基线

## 一、产品定位

本工具面向财务人员，用熟悉的项目、行项目、业务参数和分月表格完成本地测算。多维结构、公式依赖和事实汇总由系统内部处理，不要求用户直接操作 Cube。

当前产品只提供单项目测算，不建设跨项目报表、审核流或多人协作。

## 二、两层页面结构

### 2.1 外层工作台

- 项目列表：新建项目、进入项目、归档项目。
- 归档项目：查看和恢复已归档项目。
- 主数据：只维护项目、部门、业务模块、期间、场景和版本。
- 指标管理：统一查看基础指标和系统计算指标。

项目只能从项目中心创建；保存后自动成为只读项目主数据。部门可以独立维护，业务模块在项目内维护。

### 2.2 项目工作区

进入项目后固定为三个步骤：

1. **预测配置**
   - 直接编辑项目信息和业务模块。
   - 维护项目参数和收入、成本、收款、付款行项目。
   - 使用固定月金额、逐月填写或公式计算。
   - 通过“保存草稿”或“保存并计算”提交配置。
2. **计算表格**
   - 只读显示最后一次成功计算批次。
   - 展示行项目分月结果、基础事实和系统计算指标。
   - 显示公式来源、依赖参数和配置快照。
3. **项目报表**
   - 查看分月损益、现金流、项目周期汇总和指标说明。
   - 与计算表格读取同一份 `fact_metric_value`，不维护第二套页面公式。

## 三、核心用户链路

```text
新建或进入项目
  → 编辑项目信息和业务模块
  → 维护项目参数
  → 配置预测行项目
  → 保存并计算
  → 查看计算表格
  → 查看项目报表
```

配置修改后，上一批成功结果继续保留，但必须显示“结果需要重新计算”。计算失败不得覆盖上一批成功结果。

## 四、状态和维度

- 项目状态只有“测算中”和“已归档”。
- 场景是平台级维度，当前只启用“基准场景”。
- 版本是平台级维度，当前只启用可变“工作版”。
- 期间后台字段统一为 `period`，前端显示“期间”。
- 业务模块属于项目，行项目必须选择当前项目的模块，默认使用“公共”。

## 五、运行边界

- PWA 是正式本地运行方式，SQLite 通过 OPFS 自动持久化。
- 单 HTML 使用内存 SQLite，可计算、导入和导出数据库；刷新或关闭前必须导出。
- 当前不提供税规则、账期自动现金流、多场景、版本快照、Excel 和图表报告。
