- PWA 开发地址：`http://127.0.0.1:5173/`
- 普通构建：`dist/`
- 便携单文件：`dist-singlefile/index.html`

PWA 自动持久化 SQLite；单 HTML 刷新或关闭前必须导出 `.sqlite3`。
