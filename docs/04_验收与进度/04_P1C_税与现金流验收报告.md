## 3. 计算核对

### 3.1 税口径

| 用例 | 输入 | 核对结果 |
|---|---:|---:|
| 含税收入 | 含税 106，税率 6% | 未税 100，税额 6，结算额 106 |
| 未税成本 | 未税 100，税率 6% | 损益 100，税额 6，结算额 106 |
| 免税 | 金额 100 | 未税与结算额均为 100 |
| 公式引用 | 下游引用含税上游行 | 读取上游标准化未税值 |

### 3.2 收付款

| 用例 | 规则 | 核对结果 |
|---|---|---|
| 当月收款 | 偏移 0，100% | 落在业务发生期间 |
| 延后收款 | 延后 3 个月 | 落在第 3 个自然月后的期间 |
| 分期付款 | 0 月 50%，1 月 50% | 两期均生成且合计等于结算额 |
| 尾差 | 33.3333% + 66.6667% | 最后一期吸收 6 位小数尾差 |
| 非法规则 | 重复偏移、比例非 100%、偏移 37 个月 | 阻止计算并给出定位问题 |

## 5. 浏览器验收

在 PWA 开发运行方式中完成真实流程：

1. 打开河北有线互联网电视项目。
2. 将收入行设置为含税、税率 6%、延后 3 个月收款。
3. 将成本行设置为未税、税率 6%、按当月和次月各 50% 付款。
4. 保存并计算成功，进入计算表格。
5. 现金计划追溯显示来源损益行、业务发生期间、未税额、税额、含税额、规则、结算期间和实际收付款。
6. 报表经营期为 2026-08 至 2026-12，现金回收期延伸至 2027-03。
7. 回收期月份在损益和现金流表中有独立视觉标识。
8. 最大垫资和现金转正期间正常计算。

浏览器控制台无错误或警告。右侧“金额与公式 / 税与收付款”二级页签固定在配置面板顶部，滚动表单时仍可操作。

## 7. 已知边界

- 当前税额只是结算金额换算结果，不形成应交税费或税务报表。
- 收付款偏移按自然月，不支持日期级账期。
- 回收期最长为经营期后 36 个月。
- 项目报表仍为表格报告；Excel、图表和正式文件导出属于 P1D。
