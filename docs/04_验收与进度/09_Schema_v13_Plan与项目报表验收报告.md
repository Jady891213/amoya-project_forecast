# Schema v13 Plan 与项目报表验收报告

验收日期：2026-08-04  
状态：通过

## 1. 数据结构

- 空库初始化为 Schema v13。
- 新库包含 `dim_plan`，不包含 `dim_version`、`rel_project_version` 或业务 `version_id`。
- 五个参考项目各初始化一个有效默认 Plan。
- 配置、覆盖、批次、行项目结果、现金追溯和基础事实均使用 `plan_id`，并受 Project–Plan 组合外键约束。

## 2. 计算基线

重建前保存了 v12 基础事实基线；v13 重建后按“项目＋期间＋基础指标＋值”双向集合比较：

```text
v12 基础事实：276 条
v13 基础事实：276 条
v13 - v12 差异：0 条
v12 - v13 差异：0 条
```

因此五个参考项目的收入、成本、现金流入、现金流出及其派生结果未发生口径漂移。

## 3. 功能验收

- Plan 空白新建、复制、切换、重命名、设默认、归档与恢复已接入语义接口。
- 不同 Plan 的配置、修订、计算批次、事实和报告相互隔离。
- 根目录入口已改为“项目报表”。
- 项目报表支持 POV、多个行维度、多个列维度和所有行列维度的成员范围；成员可搜索、全选、清空，轴内维度可前后调整。
- 期间可作为 POV、行或列维度，并支持范围选择和单月取消。
- Plan 按所属项目分组，不生成非法 Project × Plan 组合，也不跨 Plan 汇总。
- 结果表使用多级表头，支持 Excel 式矩形选区、Shift 扩展、行列标题选区和 TSV 复制。
- 支持元、千元、万元，小数位、千分位和负数样式。

## 5. 已知边界

- 场景当前固定为基准场景。
- 项目报表只读，不提供跨项目回写。
- 本轮不提供“每个项目选一个推荐 Plan 后再形成投资组合合计”的额外语义。
- v12 数据库不自动迁移，只保留重建前备份用于回查。
