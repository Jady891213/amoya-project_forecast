## 一、当前架构结论

同一套 React + TypeScript 源码保留两种运行能力：

- 正式版：本地 TypeScript 服务托管前端，并把页面查询和写入实时同步到 `data/amoya_project_forecast.db`。
- 兼容单 HTML：内存 SQLite + 数据库文件手动导入导出，仅按需构建。

当前已形成的最小链路：

```text
真实项目与六类主数据（P0）
  → 损益、现金计划预测行配置（P1A）
  → 项目参数与行项目公式（P1B）
  → 税口径与收付款规则（P1C）
  → 项目聚合保存与期间覆盖（Schema v7）
  → 预测编译与计算批次
  → SQLite多维基础事实
  → 系统指标查询计算
  → 可编辑计算底表
  → 页面、Excel 与打印报告
```

不建设跨项目分析。用户真实项目不会自动附加参考事实；第一次真实“保存并计算”后，当前项目工作版只使用新批次结果。

## 五、当前明确不做

- 可编辑跨项目报表；当前仅提供只读预制多维事实透视。
- 多人协作、权限、审核和审批。
- 工具内置 AI。
- 任意脚本公式。
- 日期级资金计划。
- 客户级 Excel 模板定制。
- Electron、Tauri、DMG、EXE 或 SQLite 之外的第二套业务存储。
- 完整增值税核算、多场景、只读发布快照、Excel 输入或客户定制 Excel 模板。
