# 项目核心重构与正式输出验收报告

验收日期：2026-08-01  
数据库：Schema v7

## 一、结论

里程碑 A“项目核心重构”和里程碑 B“正式输出”已完成代码实现与本机验收。正式运行链路已经从前端 SQL 桥接切换为语义化 API，项目采用聚合草稿统一保存，计算工作表支持可追溯期间覆盖，页面报告、打印和 Excel 读取同一个成功计算批次。

## 二、里程碑 A 验收

### 架构与接口

- `app/server/shared` 分层完成。
- 正式页面只使用 `ApiClient` 的业务接口；原始 SQL API 返回 404。
- 项目、配置、参数、现金规则和覆盖值一次保存。
- Schema v1～v6 可幂等升级到 v7。
- 修订号冲突返回 409，失败保存恢复原数据库状态。
- 正式 URL 可直接刷新并恢复项目页面。

### 工作区与表格

- 新建项目直接进入独立配置页面，不弹出完整编辑框。
- 项目配置采用上下结构：项目信息固定在上方；损益预测、直接现金和项目参数在下方通过紧凑左侧导航切换，右侧统一展示明细表格和无蒙层编辑区。
- 顶部统一“保存”和“计算”，取消区域级保存按钮。
- `FinancialGrid` 支持框选、键盘导航、TSV 复制粘贴、清空、填充、撤销重做和只读保护。
- 计算工作表只允许覆盖叶子行，汇总与派生指标只读。
- 人工覆盖显示角标、原值和当前值，并可清除。

### 实际业务链路

在隔离数据库中使用河北有线项目完成：

```text
原收入叶子值 59,818.867925
→ 人工覆盖为 70,000
→ 保存项目草稿
→ 重新计算生成 RUN-0003
→ 下游支付费、渠道分成和毛利同步变化
```

2026-08 结果为：收入 70,000，成本 45,619.886792，毛利 24,380.113208。证明覆盖值进入确定性计算链路，而不是只修改表格展示。

## 三、里程碑 B 验收

- 报告支持选择历史成功批次。

### 统一 Excel

统一 Excel 已生成并通过程序读取、公式错误扫描和七张工作表逐页渲染检查：

1. 项目信息。
2. 测算假设。
3. 分月损益。
4. 分月现金流。
5. 行项目计算明细。
6. 收付款追溯。
7. 指标和公式说明。

Excel 使用数值和百分比单元格类型、统一标题与表头、冻结窗格、筛选、打印区域、列宽和负数格式。人工覆盖单独着色并附原值批注。未发现 `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?` 或 `#N/A`。
