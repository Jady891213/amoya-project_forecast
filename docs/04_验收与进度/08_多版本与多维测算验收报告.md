# 多版本与多维测算验收报告

验收日期：2026-08-04  
适用版本：Schema v12

## 一、结论

已完成“唯一基准场景 + 项目多版本 + 全局多维事实视图”闭环：

- 平台固定维护 `working`、`version_1`、`version_2`、`version_3` 四个版本成员；同一项目可启用多个相互独立的版本。
- 项目配置、计算底表、项目报告和 Excel 使用同一版本上下文。
- 保存、计算批次和正式事实均按版本隔离。
- 全局多维视图可比较跨项目及同项目多版本事实。

V3.1 原型中的“模式”已按最终决策映射为版本，场景保持唯一“基准场景”。

## 二、结构与接口验收

- Schema 版本：12。
- 新增 `rel_project_version`，每个参考项目自动建立“基准方案”。
- `cfg_model_line`、`cfg_forecast_override`、计算批次和三类事实均包含版本坐标。
- 计算批次号按“项目 + 版本”递增。
- 新增项目预置版本启用接口及 `/api/facts/pivot` 语义接口；接口拒绝任意版本编码。
- 前端未增加 SQL 查询入口。

当前开发库重建结果：

- 5 个参考项目。
- 5 条默认项目版本关系。
- 276 条基础指标事实。
- 参考项目历史收入、成本和现金基线保持原核对结果。

## 三、自动化验收

自动化覆盖：

- 空库 Schema v12 幂等初始化。
- 项目版本配置、逐月值、覆盖和计算批次隔离。
- 复制版本后分别保存和计算。
- 基准方案与版本 1 的收入事实不串数。
- 只允许启用四个系统预置成员，任意自定义版本编码会被拒绝。
- 报告版本名称和派生指标版本坐标正确。
- 多维透视重算收入、毛利和毛利率。
- 原 5 个参考项目历史关键结果保持不变。

结果：12 个测试文件、49 项用例通过。

## 四、浏览器验收

在本地服务 `http://127.0.0.1:4173/` 验证：

- 左侧出现“多维测算”入口。
- 项目页面显示“基准方案”版本栏；增加版本时只能选择尚未启用的版本 1、版本 2、版本 3，并支持空白启用或复制当前配置，不提供自由新建和重命名。
- 项目配置、计算底表和项目报告共享同一版本查询参数。
- 多维视图默认读取 276 条基础事实。
- “项目 × 版本”预置正确显示 5 个项目的收入、成本、毛利、毛利率和现金指标。
- “版本分月”预置自动聚焦单个项目，期间按时间顺序排列。
- 行列轴交换、维度增删、项目/期间/指标筛选控件可用。
- 页面控制台无错误或警告。

浏览器验收期间发现并修正：最初“版本分月”在全部项目下会聚合不同项目且期间首次出现顺序不稳定；现已自动选择一个项目，并为期间、版本和指标增加稳定排序。

## 五、构建验收

- TypeScript 正式构建通过。
- Web 构建通过。
- 兼容单 HTML 构建通过。
- ECharts 报告仍独立分包，构建存在体积提示但不影响运行。

## 六、当前边界

- 场景保持唯一基准场景。
- 当前版本是可编辑方案，不是审批或发布快照。
- 多维测算只读，只读取成功计算事实，不读取实时草稿。
- 多版本融合报告、多工作表对比 Excel、版本发布和历史批次恢复仍属于后续增量。
