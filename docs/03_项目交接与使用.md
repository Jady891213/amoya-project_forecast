# 项目交接与使用

更新时间：2026-08-05
适用对象：财务用户与协助维护项目的 WorkBuddy

## 1. 财务用户怎么使用

Windows 日常只需要双击根目录：

```text
启动项目测算.cmd
```

浏览器会自动打开 `http://127.0.0.1:4173/projects`。页面保存会实时写入：

```text
data/amoya_project_forecast.db
```

重要修改、升级代码或更换电脑前，先在页面左下角点击“备份”。备份文件固定名为 `amoya_project_forecast.db`，请不要改名。恢复时点击“恢复”，在预览窗口拖入或选择这个文件，确认无误后再替换当前数据。不要在服务运行时用其他 SQLite 软件写这个数据库。

## 2. 第一次安装

目标电脑需要 Node.js 和 pnpm。建议让 WorkBuddy完成一次性安装：

```bash
cd src
pnpm install
pnpm start:local
```

以后直接双击启动文件即可。如果出现“未找到 pnpm”，让 WorkBuddy检查 Node.js、pnpm 和网络，不要求财务用户自行排查命令行。

## 3. 交给 WorkBuddy 时怎么说

把整个项目目录交给 WorkBuddy，并直接说明：

> 请先完整阅读项目根目录 `AGENTS.md`，再检查当前 Git 状态和数据库备份情况。按照其中的启动、数据安全、业务口径和验证要求协助我使用或修改项目，不要恢复旧单 HTML、PWA 或浏览器数据库方案。

`AGENTS.md` 是唯一必读入口；本文用于展开普通用户的使用步骤。

## 4. 目录职责

```text
amoya-project_forecast/
├── AGENTS.md                 WorkBuddy 唯一交接入口
├── README.md                 项目简介
├── 启动项目测算.cmd           Windows 日常入口
├── 启动项目测算.command       macOS 日常入口
├── src/                      完整源码、依赖、测试和服务
├── data/                     SQLite 业务数据
├── docs/                     当前设计、验收、交接和必要素材
└── dist/                     自动生成的网页构建，可删除重建
```

`dist/` 不是源码或数据，不应手工修改，也不需要提交 Git。

## 5. WorkBuddy 修改流程

1. 阅读根 `AGENTS.md`。
2. 执行 `git status --short`，不要覆盖用户未提交改动。
3. 在页面备份数据库，或复制 `.db` 并标记 `TMP to delete`。
4. 修改 `src/`；提示词配置只改 `src/config/prompts/`。
5. 执行 `cd src && pnpm test && pnpm build`。
6. 重启服务并检查目标页面。
7. 更新必要文档和版本号；提交说明使用中文。

## 6. 代码和数据分开备份

- Git 管理源码和文档，不包含真实 `.db`。
- `data/amoya_project_forecast.db` 管理业务数据，必须单独备份。
- 页面备份和恢复只认统一文件名 `amoya_project_forecast.db`；如果浏览器下载时自动添加了编号，应先改回统一名称。
- 仅从 Git 克隆项目时，需要把已有 `.db` 另行放回 `data/`；没有数据库时系统会初始化参考开发库。
