# 项目交接与使用

更新时间：2026-08-05
适用对象：财务用户与协助维护项目的 WorkBuddy

## 1. 财务用户怎么使用

Windows 日常只需要双击根目录：

```text
启动项目测算_Windows.cmd
```

浏览器会自动打开 `http://127.0.0.1:4173/projects`。页面保存会实时写入：

```text
data/amoya_project_forecast.db
```

重要修改、升级代码或更换电脑前，先在页面左下角点击“备份”。备份文件固定名为 `amoya_project_forecast.db`，请不要改名。恢复时点击“恢复”，在预览窗口拖入或选择这个文件，确认无误后再替换当前数据。不要在服务运行时用其他 SQLite 软件写这个数据库。

## 2. 第一次安装

目标电脑需要 Node.js 和 pnpm。建议让 WorkBuddy完成一次性安装：

```bash
cd src
pnpm install
pnpm start:local
```

以后直接双击启动文件即可。如果出现“未找到 pnpm”，让 WorkBuddy检查 Node.js、pnpm 和网络，不要求财务用户自行排查命令行。

WorkBuddy 接手时应先判断当前电脑是 Windows 还是 macOS，再选择对应启动文件；不要让用户同时尝试两套命令。若依赖已经存在，不重复安装或升级环境。

## 3. 临时在局域网使用

局域网访问是可选功能，不会随普通启动自动开启。需要让同一家庭或办公网络里的另一台电脑查看时，WorkBuddy 必须先询问并获得使用者确认，然后才能在 `src` 目录运行：

```bash
pnpm start:lan
```

启动窗口会同时显示：

```text
本机访问地址：http://127.0.0.1:4173
局域网访问地址：http://当前电脑的局域网IP:4173
```

另一台设备连接同一个可信网络后，打开显示的“局域网访问地址”。该功能仍共用同一个本地数据文件，不适合多人同时编辑；不要在公共 Wi-Fi、公网或端口映射环境使用。使用结束后关闭启动窗口即可停止共享。

## 4. 交给 WorkBuddy 时怎么说

把整个项目目录交给 WorkBuddy，并直接说明：

> 请先完整阅读项目根目录 `AGENTS.md`，再检查当前 Git 状态和数据库备份情况。按照其中的启动、数据安全、业务口径和验证要求协助我使用或修改项目，不要恢复旧单 HTML、PWA 或浏览器数据库方案。

`AGENTS.md` 是唯一必读入口；本文用于展开普通用户的使用步骤。

## 5. 目录职责

```text
amoya-project_forecast/
├── AGENTS.md                 WorkBuddy 唯一交接入口
├── README.md                 项目简介
├── 启动项目测算_Windows.cmd       Windows 日常入口
├── 启动项目测算_macOS.command     macOS 日常入口
├── src/                      完整源码、依赖、测试和服务
├── data/                     SQLite 业务数据
├── docs/                     3 份当前文档和必要需求素材
└── dist/                     自动生成的网页构建，可删除重建
```

`dist/` 不是源码或数据，不应手工修改，也不需要提交 Git。

`docs/04_需求素材` 保留历史 Excel 和 V3.1 样例，方便核对来源与输出样式；它不是日常使用入口，也不代表当前页面必须照搬所有旧字段。

## 6. WorkBuddy 修改流程

1. 阅读根 `AGENTS.md`。
2. 执行 `git status --short`，不要覆盖用户未提交改动。
3. 在页面备份数据库，或复制 `.db` 并标记 `TMP to delete`。
4. 修改 `src/`；提示词配置只改 `src/config/prompts/`。
   收入成本指标分类只改 `src/config/profitMetricHierarchy.ts`；修改编码时必须同步检查现有数据库数据与报告。
5. 执行 `cd src && pnpm test && pnpm build`。
6. 重启服务并检查目标页面。
7. 更新必要文档和版本号；提交说明使用中文。

## 7. 代码和数据分开备份

- Git 管理源码和文档，不包含真实 `.db`。
- `data/amoya_project_forecast.db` 管理业务数据，必须单独备份。
- 页面备份和恢复只认统一文件名 `amoya_project_forecast.db`；如果浏览器下载时自动添加了编号，应先改回统一名称。
- 仅从 Git 克隆项目时，需要把已有 `.db` 另行放回 `data/`；没有数据库时系统会初始化参考开发库。

## 8. v0.7.0 分类口径

- 新建项目首个方案会看到 4 条收入和 15 条成本默认行，金额均为 0，直接填写或删除即可。
- 收入、成本预测项必须选择末级分类；父级只用于汇总和报表查询。
- 修改分类不会改变预测金额，但重新计算后会改变事实归属、底稿分组、项目报表和 Excel 展示。

## 9. 日常界面提示

- 左上角显示当前软件版本；确认对方是否已更新时，优先核对这里。
- 点击左上角红色 B 标识可以收起或展开侧栏。
- 主数据和指标管理的表头分隔线可以左右拖动，调整后的列宽只保存在当前浏览器，不影响数据库。
- 项目内点击“方案对比”会进入项目报表，默认按“方案 → 年度”展示当前项目全部有效方案；右侧仍可改成月度、季度或其他行列结构。
- 项目报表的“下载”导出当前可见表样，包含多层中文表头和原始数值；页面上的万元、小数位等仅影响屏幕显示。
