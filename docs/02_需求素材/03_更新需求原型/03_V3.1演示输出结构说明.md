# V3.1 演示输出结构说明

## 1. 演示项目

- 项目名称：华东电信云游戏增值服务项目
- 申报部门：互联网电视事业部
- 项目周期：2026-01 至 2026-12
- 测算方案：基准方案
- 填报口径：收入、成本输入为含税金额；报告默认展示不含税结果
- 数据性质：全部为模拟数据，不代表真实业务结论

演示页：`02_测算项目V3.1_已填报演示.html`

## 2. 页面输出故事线

结果页按以下顺序组织：

1. 核心指标：收入、成本、利润、利润率、ROI。
2. 单用户单月指标：收入、成本和利润的人均月度结果。
3. 测算假设：列明单价、数量、周期、收入比例和税率。
4. 收入结构：展示各收入项金额和占比。
5. 成本结构：按商务、技术、版权、营销、人力五类展开成本项。
6. 年度分布：按自然年汇总收入、成本、利润和利润率。
7. 主要结论：输出盈利性判断和需要重点复核的假设。

## 3. 下载文件结构

### Excel

单方案固定包含两个工作表：

1. `测算报告`
   - 项目及方案信息。
   - 核心指标。
   - 测算假设与输入。
   - 年度利润情况。
   - 主要结论和口径说明。
2. `月度明细`
   - 行为收入、成本及其明细项。
   - 列为项目周期内月份，最后一列为合计。
   - 展示利润、利润率和用户数。

多方案时，可在上述结构上增加一张融合对比报告，并为每个方案分别输出报告和月度明细。

### PDF / 打印

沿用页面结果故事线，重点保留测算假设、主要结论和年度利润表，适合审阅和归档。

### CSV

作为机器可读明细，保留项目属性、含税与不含税指标以及收入、成本逐项记录，不承担正式报告排版。
