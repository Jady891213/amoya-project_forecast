# 产品与数据设计

更新时间：2026-08-05
当前版本：v0.7.0
数据结构：Schema v15

## 1. 产品目标

这是一个面向财务人员的本地项目测算工具。用户按熟悉的业务参数、收入、成本和收付款事项建模，系统负责把配置编译为分月事实、计算指标并输出报告。

产品只保留三条核心链路：

```text
项目配置 → 计算底稿 → 项目报告
项目与方案事实 → 项目报表（跨项目多维查询）
项目报告 → Excel / 打印 PDF / AI 分析素材
```

工具本身不调用 AI，不建设多人协作、审批或云数据库。

运行方式以单机本地服务为主；经使用者明确确认后，可由 WorkBuddy 临时开启可信局域网访问，但这不等于多人协作，同一时间仍应避免多人同时修改同一项目。

## 2. 核心业务对象

- Project：项目主数据，保存项目编码、项目名称、申报部门和状态。
- Plan：项目下的测算方案，保存方案名称、起止期间、排序和状态。项目至少保留一个有效方案。
- Scenario：当前固定为“基准场景”。
- Period：期间，后台格式为 `YYYY-MM`；项目报表支持月、季度和年度聚合。
- Metric：统一指标维度，区分汇总指标、末级基础指标和系统计算指标。
- Model Line：统一行项目，类型包括参数、收入、成本、其他收款和其他付款。

Plan 从属于 Project，不设置默认方案；未指定方案时进入排序最前的有效方案。

## 3. 配置与计算

项目方案的参数和预测项统一保存：

```text
cfg_model_line
  公共字段：名称、类型、测算方式、期间、排序
  config_json：单价数量、比例、公式、税和收付款等差异配置

cfg_model_line_value
  逐月填写值
```

支持的主要测算方式：

- 全期固定。
- 逐月填写。
- 受限公式。
- 收入快捷方式“单价 × 数量”。
- 成本快捷方式“按收入比例”。

公式只允许四则运算、括号、百分数字面量、参数引用和其他预测项引用；必须检测缺失引用、除零和循环依赖。金额计算使用 Decimal.js，不使用 JavaScript 浮点数。

收入和成本统一以未税金额进入损益事实。损益行可配置含税、未税或免税；收付款规则支持当月、延后和自定义分期，并生成可追溯现金计划。

## 4. 最新结果与人工调整

当前只保留每个 Plan 的最新结果：

```text
参数与预测项配置
  → 点击“计算”
  → fact_forecast_line_value（最新原始行项目结果）
  → fact_cash_schedule_value（最新现金计划）
  + fact_metric_adjustment（人工绝对值调整）
  → fact_metric_value（最终基础事实）
  → 派生指标、报告和项目报表
```

人工调整不回写项目配置，不参与预测项公式、税额或自动现金计划。保存调整后立即更新最终事实和派生指标，不需要再次计算。

每个 Plan 只在 `sys_plan_calculation_state` 保存一条最新计算状态，不保存前台可切换的历史 Run。

## 5. 事实与指标

最终基础事实坐标：

```text
项目 × Plan × 部门 × 期间 × 场景 × 指标
```

损益事实只落在末级指标，父级不重复存储：

```text
收入（汇总）
  项目服务费 / 年度订阅费 / 增值收入 / 其他收入（末级）

成本（汇总）
  商务 / 技术 / 版权 / 营销 / 人力成本（汇总）
    每类 3 个末级成本分类
```

完整指标树由 `src/config/profitMetricHierarchy.ts` 统一定义。预测行是项目明细，必须选择合法末级指标；同一末级可有多条预测行。查询收入、成本或成本大类时递归汇总全部末级后代，毛利和毛利率基于汇总后的收入、成本重新计算。月、季度、年度都先聚合末级事实，再计算父级和派生指标，禁止父子重复相加。

现金流入、现金流出仍是独立末级基础指标。毛利、毛利率、净现金流和累计现金流等派生指标不作为平行输入事实维护。

## 6. 页面与输出

- 项目列表：查看测算中或已归档项目；支持复制、归档、恢复和删除。
- 主数据：只读项目和方案，以及可维护部门、期间和场景。
- 指标管理：树形查看收入两级、成本三级、现金基础指标和系统计算指标；主数据和指标表均可拖动列宽。
- 项目配置：项目信息、方案、参数和预测项；左侧分月表实时预览，右侧抽屉编辑配置。
- 计算底稿：查看原始结果，对基础叶子单元格进行可追溯人工调整。
- 项目报告：V3.1 业务报告风格，支持含税/不含税、元/万元切换。
- 项目报表：背景、行轴和列轴多维查询，支持跨项目、跨 Plan、指标父子层级及月/季度/年度比较。

新建项目首个“方案 1”自动生成 19 条零金额预测项：4 条收入末级、15 条成本末级，均不自动生成现金。用户可以直接填写、改名、改测算方式或删除；后续新建空白 Plan 不自动生成这些行。

Excel 固定输出“测算报告”和“月度明细”两个工作表，完整保留收入两级和成本三级结构。AI 分析素材使用同一报告模型和层级，标准分类不脱敏、项目预测项使用别名；项目身份会隐藏，但真实财务数值仍保留。

## 7. 当前边界

暂不包含：完整增值税核算、日期级账期、多场景、发布快照、Excel 输入模板、客户定制模板、审批、权限、多人协作和内置 AI。

`04_需求素材` 中的原始文件用于核对历史业务口径和 V3.1 输出样式。素材可能包含已被当前产品替代的字段或交互，当前实现以本文、代码和 Schema v15 为准。
