## 6. 当前运行入口

日常使用双击项目根目录的启动文件；开发时：

```bash
cd src
pnpm start:local
```

- 地址：`http://127.0.0.1:4173/`
- 数据库：`data/amoya_project_forecast.db`
- 正式前端：`output/web/`
- 兼容单文件：按需生成到 `output/legacy-singlefile/`
