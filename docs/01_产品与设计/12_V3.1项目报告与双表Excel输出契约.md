# V3.1 项目报告与双表 Excel 输出契约

更新时间：2026-08-05

适用版本：v0.5.12 / Schema v14

## 一、统一数据链路

```text
项目 + Plan
→ 最新成功计算形成的最终事实
→ ProjectReportDto.presentation
→ 页面报告 / 打印报告 / Excel
```

页面和 Excel 不得自行重算预测公式，也不得从未计算草稿读取金额。人工底稿调整已经进入最终事实，因此会同步进入页面和 Excel，但不会反向改变预测项公式或自动收付款计划。

## 二、页面报告

项目报告按 V3.1 已填报演示的业务故事线组织：

1. 项目名称、编码、申报部门、项目周期、Plan 和结果口径。
2. 收入、成本、利润、利润率和 ROI。
3. 存在用户数或人数类数量参数时，展示单用户单月收入、成本和利润。
4. 展示业务参数、收入成本预测项、测算方式、主要配置、税率和未税合计。
5. 分别展示收入结构和成本结构的金额、占比与来源。
6. 按自然年展示收入、成本、利润和利润率。
7. 使用确定性规则生成“测算结论”和风险提示，不调用 AI。

页面采用蓝色主色、浅色背景、白色自适应卡片和紧凑财务信息层级。常见窗口尺寸下不得出现卡片内容重叠或固定高度裁切。

## 三、Excel 模板

单项目、单 Plan 导出固定只有两张表：

### 1. 测算报告

- 报告标题及项目、Plan、口径、单位、日期。
- 核心指标。
- 测算假设与输入。
- 年度利润情况。
- 主要结论与口径说明。

### 2. 月度明细

- 行：收入、收入明细、成本、成本明细、利润、利润率及业务参数。
- 列：经营周期各期间，最后一列为周期合计。
- 冻结前四行和第一列。
- 汇总、利润和利润率使用 Excel 公式；明细和参数保持数值类型。

## 四、格式约束

- 默认金额单位为万元，保留两位小数并使用千分位。
- 百分比保留两位小数。
- 负数使用红色括号样式。
- 可调整假设使用蓝色字体，计算结果使用黑色字体。
- 收入、成本、利润及利润率使用固定分组底色。
- 使用微软雅黑字体、统一边框、列宽、打印区域和横向打印设置。
- 文件名包含项目编码、项目名称、Plan 名称和导出日期。
- 不增加第三张工作表，不再输出早期七表模板。

样式配置集中在 `src/server/reportTemplates/v31ProjectReportTemplate.ts`；Excel 生成只允许消费统一报告模型。

## 六、AI 分析素材

项目报告提供“AI 分析素材”入口，但工具不调用模型、不要求 API Key，也不保存 AI 分析结果。

- 弹框只读展示一套固定提示词，支持复制。
- 只有当前 Plan 存在最新成功结果且配置未过期时，才能下载脱敏数据源。
- 脱敏文件继续使用“测算报告、月度明细”两张表，并与页面报告读取同一个 `ProjectReportDto`。
- 项目、Plan、部门、客户、产品、人员、自由文本、来源文件和路径必须移除或别名化。
- 参数、收入、成本、收款和付款按类别稳定编号；公式说明同步替换引用名称。
- 真实期间、金额、数量、比例、税率和现金流保持不变，因此必须明确提示“财务数值未脱敏”。
- 脱敏文件名、工作簿属性、隐藏内容和单元格均不得包含真实身份信息。
